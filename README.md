# GHL Prime

A premium one-page React landing page for **GHL Prime**, built with Vite.

## Current scope

- High-end responsive homepage
- Motion-driven hero and UI sections
- Premium SaaS-style visual system
- Structured to expand into future dynamic/project-driven pages

## Stack

- React
- Vite
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Future roadmap

Planned next-phase additions:

- MongoDB-backed project/service content
- Dynamic case studies or project pages
- API layer for content delivery
- Contact capture and CRM integrations
- Admin-editable content model

## Suggested future backend shape

Collections that would fit well later:

- `projects`
- `services`
- `testimonials`
- `site_settings`
- `contact_submissions`

This version is intentionally focused on creating a top-tier homepage foundation first.
